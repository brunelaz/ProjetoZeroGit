# Exercício de IFDS - Git e Terminal Linux

Repositório criado para a disciplina de Informática e Ferramentas para Desenvolvimento (IFDS) do curso técnico de Desenvolvimento de Sistemas no IFSP.

## Objetivo
Praticar a inicialização de repositórios, a criação de commits e a manipulação de arquivos diretamente pelo terminal do Debian Linux utilizando comandos do Git.

## Tecnologias e Ferramentas
- Debian Linux
- Git / GitHub
- Terminal (Linha de Comando)
